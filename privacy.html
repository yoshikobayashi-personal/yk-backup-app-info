Privacy policy

For YK Backup Pilot 20261020 (Personal). Last updated: 20 October 2026.

Data and purpose

This owner-operated app reads Dropbox file contents and metadata to create backups in the owner's Google Drive. It uses Google's drive.file permission for app-created backup files and folders, including reading them for verification and restoration. Account identity and storage-quota information are used to check the intended account and available capacity.

Storage and sharing

Credentials are stored with owner-only file permissions on the owner's computer. Backups and retained versions are stored in the owner's Google Drive. Dropbox and Google process data as required to provide these services. The app does not sell data, use it for advertising, or intentionally publish or share backup contents with other users.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The owner controls retention and may manually delete backup files and versions in Google Drive, and stored credentials on the owner's computer. Access can be revoked through the Google Account connections settings and Dropbox connected-app settings. Revoking access does not automatically delete existing backups or local credentials.

This website

These information pages contain no analytics, advertising, forms, or external scripts. They do not receive backup contents or credentials. GitHub Pages may log visitors' IP addresses for security purposes under the GitHub Privacy Statement.
