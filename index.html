Personal backup application

YK Backup Pilot 20261020 (Personal)

A personal tool for one-way backups from the owner's Dropbox to the owner's Google Drive, including version history and restoration.

Dropbox is accessed read-only. Google Drive access uses the limited drive.file permission for files created by this app. The app is for its owner's use, not a public backup service.

This website provides application information only. It does not accept sign-ins, credentials, uploads, or backup data.
